# Security policy

This software handles family-law casework, much of it for survivors of domestic abuse. Please report security problems privately.

## Reporting a vulnerability

Email **security@caseforge.uk** with:

- what you found and where (a file and line, or the behaviour you saw);
- the steps to reproduce it;
- what you think the impact is;
- how to contact you, and whether you would like to be credited.

Do not open a public issue or post the details anywhere public until a fix is available.

## Scope

In scope: the code in this repository, including the hub API, the CRM, the workers, the document and form tools, and the configuration templates.

Out of scope: a deployment run by someone else (report it to them), third-party services the code talks to (Microsoft 365, Azure, Cloudflare, Documenso, OpenRouter), social engineering, physical access and denial-of-service testing.

## What to expect

- An acknowledgement within 2 working days.
- A first assessment within a week.
- A fix on a timescale that depends on severity. An issue that could expose client data comes first.

## Good faith

If you research in line with this policy, report promptly and do not access, keep or share more data than you need to show the problem, we will not take legal action against you. Never test against a real firm's deployment or real client data.
